Custom Media Queries

These three responsive examples share a single breakpoint defined using @custom-media. Changing the breakpoint token and rebuilding the CSS updates all three components without modifying their individual styles.

1. Navigation

Links stack vertically on smaller screens and switch to a horizontal row at 48em.

2. Content Layout

Sidebar and main content stack on smaller screens, then sit side by side from 48em up.

Sidebar

Main Content
