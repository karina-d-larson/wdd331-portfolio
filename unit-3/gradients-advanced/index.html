Advanced Gradients and @property

Explore repeating and tiled gradients, CSS-only patterns, and how @property unlocks smooth gradient animations.

Repeating vs. Tiled Gradients

Repeating Gradient

repeating-linear-gradient() repeats the pattern based on its color stop positions. Here, a 10px stripe and 10px gap form a 20px cycle that continues across the element.

Tiled Gradient

A regular linear-gradient() defines a single tile with percentage-based stops. background-size sets the tile dimensions, and background-repeat tiles that unit across the element.

Gradient Patterns

Stripes

A tiled linear-gradient() with hard color stops creates stripes. --tile-size sets how tall each stripe cycle is.

Polka Dots

A tiled radial-gradient() draws a circle in each tile. Repeating that tile produces an even polka-dot field.

Checkerboard

Two identical diagonal linear gradients are layered and offset by half of --tile-size with calc(), filling in alternating squares.

Grid Lines

Two perpendicular linear gradients—one horizontal, one vertical—stack to form a grid. Each line is one pixel thick within the tile.

Animating Gradients with @property

Normal Gradient Transition

Transitioning background-image between two gradient angles snaps abruptly. Browsers cannot interpolate gradient functions as continuous values—hover or focus this swatch to see the jump.

Unregistered Custom Property

An unregistered custom property can hold an angle, but it still switches discretely. Without @property, the browser treats each keyframe as a separate value and cannot interpolate between them.

Registered Custom Property

Registering --gradient-angle as <angle> lets the browser interpolate the angle smoothly. The gradient rotates through intermediate values without transforming the element itself.
