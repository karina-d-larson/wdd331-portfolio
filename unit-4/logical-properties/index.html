Logical Properties and Writing Modes

Compare physical CSS properties with their logical counterparts, and see how writing modes redefine the inline and block axes.

1. Introduction

Physical properties such as margin-left, padding-top, and border-right always refer to fixed screen directions. Logical properties such as margin-inline-start, padding-block-start, and border-inline-end follow the inline and block axes of the current writing mode, so layouts adapt when direction or orientation changes.

2. Understanding the Axes

Every writing mode has an inline axis (the direction text flows within a line) and a block axis (the direction lines stack). Compare English (LTR) and Arabic (RTL): the inline arrow reverses, while the block arrow still points top to bottom.

4. Vertical Writing Modes

The same logical sizing (inline-size / block-size) and a border-inline-start accent are applied to each sample. As writing-mode changes, those logical edges map to different physical sides.

Horizontal (horizontal-tb)

  • writing-mode: horizontal-tb
  • inline-size: 11rem
  • block-size: 14rem
  • border-inline-start: 4px solid …

Lines progress top to bottom. Text flows along the horizontal inline axis from left to right.

Vertical right-to-left (vertical-rl)

  • writing-mode: vertical-rl
  • inline-size: 11rem
  • block-size: 14rem
  • border-inline-start: 4px solid …

縦書きでは文字が上から下へ進み、行は右から左へ進みます。論理的な寸法は書字方向に従います。

Vertical left-to-right (vertical-lr)

  • writing-mode: vertical-lr
  • inline-size: 11rem
  • block-size: 14rem
  • border-inline-start: 4px solid …

在垂直从左到右的书写模式中，字符从上到下排列，行从左向右推进。逻辑尺寸随书写模式变化。
